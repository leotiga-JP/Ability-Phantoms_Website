# 異能力怪盗団 キャラクター作成ツール

GitHub Pagesで公開できる、ビルド不要の静的Webアプリ版MVPです。

## 使い方

1. このフォルダをGitHubリポジトリへアップロードします。
2. GitHubの **Settings → Pages** で公開元を設定します。
3. `index.html` が置かれているブランチ/フォルダを公開します。
4. ブラウザで表示されたツールからキャラクターを作成します。

Node.js、npm、webpack、Viteなどは必須ではありません。

## ファイル構成

- `index.html` … 画面構造
- `style.css` … デザイン・レスポンシブ対応・印刷用CSS
- `app.js` … キャラクター計算、UI制御、JSON/PDF/ココフォリア出力
- `data.js` … 標準技能マスターデータ。編集しやすいように分離

## 保存について

このツールはサーバーへキャラクターデータを保存しません。

「JSON保存」を押すと、キャラクターを完全復元するための `.character.json` が保存されます。
このファイルを「JSON読込」から戻すことでUIの入力内容を復元できます。

PDFは人間が確認・印刷・共有するためのキャラクターシートです。完全復元はJSONを使用してください。

## PDFについて

通常は `html2pdf.js` をCDNから読み込んでPDFファイルを生成します。
CDNが利用できない場合はブラウザの印刷ダイアログへフォールバックします。

完全オフライン版にしたい場合は、html2pdf.jsをローカル同梱する構成へ変更できます。

## ココフォリアについて

「ココフォリアJSON」ボタンから、提示された `kind: character` 形式でJSONを出力します。
標準では以下を出力します。

- `status`: HP / PP / イニシアチブ / クリティカル値
- `params`: 身体 / 器用 / 感覚 / 知性 / カリスマ / 精神
- `commands`: 自動生成＋手動編集可能
- `memo`: キャラクター設定の要約

ココフォリア側のダイスボット設定によってコマンド記法が異なる可能性があるため、チャットパレットは自由編集可能にしています。

## 改造しやすいポイント

### 計算式を変える
`app.js` の `calculateDerivedValues()` を編集してください。

### ポイント計算を変える
`app.js` の `calculatePointPools()` を編集してください。

### 技能値計算を変える
`app.js` の `calculateSkillFinalValue()` を編集してください。

### 異能力コスト計算を変える
`app.js` の `calculateAbilityTotals()` を編集してください。

### 標準技能を増減する
`data.js` の `STANDARD_SKILLS` を編集してください。

### ココフォリア形式を変更する
`app.js` の `buildCocofoliaData()` を編集してください。


## 今回追加した機能

- 英語名を **異能力怪盗団** に統一
- キャラクター立ち絵のアップロード
- 複数の立ち絵差分登録とワンクリック切り替え
- 現在選択中の立ち絵をPDFへ出力
- 立ち絵差分をキャラクターJSON内に保存し、再読込時に復元
- 最後の変更以降PDF保存をしていない状態でページを離れる際、ブラウザ標準の確認アラートを表示

> 注意：ページ離脱確認の文言はブラウザの仕様により固定される場合があります。
> また、立ち絵はJSONに直接保存されるため、大きな画像を多く登録するとJSONファイルの容量も大きくなります。


## 第2段階：ブラウザ内自動保存

- `localStorage` を使って複数キャラクターをブラウザ内に自動保存します。
- 最後に編集していたキャラクターを次回起動時に復元します。
- 保存済みキャラクターの切り替え、複製、削除、現在キャラクターの入力クリアに対応しています。
- 立ち絵はブラウザ内の保存容量を圧迫しやすいため、画像を多数登録した場合はJSON/PDFバックアップを併用してください。
- localStorageは端末・ブラウザ単位なので、PCとスマートフォンの間では自動共有されません。

### localStorageの保存キー

- `ability-phantoms.characters.v2` … キャラクター一覧本体
- `ability-phantoms.current-character.v2` … 最後に開いていたキャラクターID

将来Supabaseへ移行するときは、`character` オブジェクトをデータベース保存へ置き換える方針を想定しています。
